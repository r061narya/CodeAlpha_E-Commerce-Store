# Simple E-Commerce Store

A simple full-stack E-Commerce Store built using **HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB**.

This project allows users to browse products, view product details, add products to a shopping cart, register/login, and place orders.

---

## Features

- Product listing
- Product details page
- Search products
- Sort products
- Add products to cart
- Increase/decrease cart quantity
- Remove products from cart
- User registration
- User login
- Password hashing using bcrypt
- Checkout page
- Order processing
- MongoDB database
- Express.js REST API
- Responsive frontend
